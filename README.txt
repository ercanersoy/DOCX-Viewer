DOCX Viewer
-----------

A DOCX Viewer for .NET Framework 4.0

Shows documents that were created with Word 2007, 2010, 2013 and 2016
(.docx, .docm, .dotx and .dotm files, transitional and strict Open XML).

Supported content: paragraph and character styles, theme fonts, alignment,
indentation, spacing, tab stops, bulleted and numbered lists, tables (merged
cells, shading and borders), pictures (PNG, JPEG, GIF, BMP, TIFF, EMF and
WMF), text boxes, content controls, hyperlinks, fields, tracked changes
(insertions shown, deletions hidden), symbols, equations (as text),
headers, footers, footnotes and endnotes.

The interface uses buttons instead of menus: Open, Copy, Select All,
Zoom Out, Zoom In, 100%, Find Next and About. Documents can also be opened by
dropping them on the window or by passing the file path as a command line
argument.

Keyboard shortcuts: Ctrl+O (open), Ctrl+F (find), F3 (find next),
Ctrl++ / Ctrl+- (zoom), Ctrl+0 (actual size).
